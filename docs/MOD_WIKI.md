## 模组简介

Resource Observer 是一个资源网络监控模组。它允许玩家在游戏内放置 **观察者方块**，并通过 **绑定工具** 将其连接到受支持的资源网络（如 AE2 物品存储网络或 Flux Networks 能量网络），从而实时监控网络中的资源生产、消耗和净变化数据。

---

## 物品与方块一览

模组添加了以下三个核心物品/方块，可在创造模式物品栏 **Resource Observer** 分类中找到：

### 1. 观察者方块（Observer Block）

- **类型**：方块
- **用途**：放置在世界中，绑定到一个资源网络后负责采样和记录网络数据。
- **硬度**：3.0 | **爆炸抗性**：6.0
- **特性**：
  - 每个观察者方块只能绑定 **一个** 资源网络。
  - 右键点击观察者方块可以查看其当前状态信息。

#### 状态显示

| 状态 | 含义 |
|------|------|
| **UNBOUND** | 未绑定，观察者尚未连接到任何网络 |
| **BOUND** | 已绑定，显示网络类型、网络 ID 和目标方块信息 |

---

### 2. 绑定工具（Binding Tool）

- **类型**：物品（不可堆叠）
- **用途**：通过两步操作将观察者方块绑定到指定的资源网络目标方块。

#### 使用方法

绑定工具采用 **两步式绑定流程**：

**第一步：选择观察者方块**
> 手持绑定工具，**右键点击** 一个已放置的观察者方块。
>
> 💬 系统消息：*"Selected observer at (X, Y, Z). Right-click a supported network target."*

**第二步：选择目标网络方块**
> 继续手持绑定工具，**右键点击** 一个受支持的网络方块（如 AE2 设备或 Flux Controller）。
>
> 💬 系统消息：*"Bound observer to [网络类型] via target [目标方块]"*

**绑定完成！** 观察者方块现在会开始监控该网络的数据。

#### 其他操作

| 操作 | 说明 |
|------|------|
| **Shift + 右键** 观察者方块 | 解除该观察者的网络绑定（💬 *"Observer binding cleared."*） |

#### 常见提示信息

| 消息 | 含义 |
|------|------|
| *"No observer selected."* | 你还没有选择观察者方块，请先右键点击一个观察者方块 |
| *"Selected observer is in a different dimension."* | 选中的观察者和目标方块不在同一个维度 |
| *"Selected observer no longer exists."* | 之前选中的观察者方块已被破坏或不存在 |
| *"Unsupported target block: xxx"* | 你点击的方块不是受支持的网络目标 |

---

### 3. 资源终端（Resource Terminal）

- **类型**：物品（不可堆叠）
- **用途**：计划中的数据查看终端。未来右键使用可打开 GUI 界面，查看所有观察者的统计数据和汇总信息。
- **当前状态**：⚠️ GUI 功能尚在开发中（💬 *"Resource Terminal GUI is planned for the next milestone."*）

#### 计划功能（未来版本）
- 观察者列表面板
- 单个观察者详细数据面板
- 全局汇总面板
- 按网络类型筛选（All / AE2 / Flux）
- 显示生产量、消耗量、净变化值

## 支持的资源网络

### Applied Energistics 2（AE2）

| 项目 | 内容 |
|------|------|
| 网络类型 | `AE2_ITEMS` |
| 可绑定目标 | AE2 命名空间下的方块（如 ME 控制器、ME 驱动器等） |
| 监控内容 | 物品存储总量、物品种类数、各物品数量变化 |

### Flux Networks

| 项目 | 内容 |
|------|------|
| 网络类型 | `FLUX_ENERGY` |
| 可绑定目标 | Flux Controller（控制器方块） |
| 监控内容 | 能量存储、每 tick 输入/输出、连接器数量 |

> **注意**：MVP 版本中 Flux Networks 仅支持绑定到 Flux Controller，不支持其他 Flux 方块。

## 快速上手流程

```
1. 合成/获取 观察者方块、绑定工具、资源终端

2. 将 观察者方块 放置在你想要监控的资源网络附近

3. 手持 绑定工具 → 右键点击 观察者方块
   → 显示 "Selected observer at (X, Y, Z)..."

4. 继续手持 绑定工具 → 右键点击 目标网络方块
   （AE2 设备 或 Flux Controller）
   → 显示 "Bound observer to ..."

5. 右键点击 观察者方块 查看绑定状态

6. 如需解绑 → Shift + 右键 观察者方块
```

## 常见问题 FAQ

**Q: 一个观察者方块可以同时监控多个网络吗？**
> 不可以。每个观察者方块只能绑定一个网络。如需监控多个网络，请放置多个观察者方块。

**Q: 如何更换观察者绑定的网络？**
> 先使用绑定工具 **Shift + 右键** 观察者方块解除当前绑定，然后重新执行两步绑定流程。

**Q: 观察者方块需要放在网络方块旁边吗？**
> 不需要。绑定是通过绑定工具指定的，观察者方块可以放置在任意位置（但必须与目标方块在同一维度）。

**Q: 资源终端什么时候可以使用？**
> 资源终端的 GUI 界面计划在下一个开发里程碑中实现。目前右键使用只会显示提示消息。

**Q: 支持哪些模组的资源网络？**
> MVP 版本支持 **Applied Energistics 2**（AE2）和 **Flux Networks**。未来可能添加更多模组支持。
