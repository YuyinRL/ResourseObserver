### 变更

- **双 Token 模型重构**（[[14-Web服务]]、[[08-数据持久化]]）
  - URL 中携带的不再是长期 Token，而是**一次性 link token**（前缀 `rl_`、TTL 5 分钟、内存存储、`consumeLinkToken` 立即移除），解决"同一链接可被多个浏览器重复使用"
  - 浏览器消费链接时调 `POST /api/auth/exchange` 用 link token 换长期 **session token**（前缀 `rs_`、持久化到 SavedData、单玩家可有多个用于多设备）
  - 长期 token 同时落到 `localStorage` 与 cookie `ro_session`（`Max-Age=2592000; Path=/; SameSite=Lax`），关闭浏览器重开仍登录
  - `regenerate` 操作会调用 `revokeAllSessions(uuid)` 一并踢下所有已登录浏览器
  - 兼容旧 v0.1 SavedData：原 `entries` 数据迁移为 session token，升级用户不下线
  - `AuthFilter.extractToken` 删除 `?t=` 查询参数解析（防 token 进入 URL 历史 / Referer），统一只接受 `Authorization` 头与 cookie

  - `StaticHandler` 新增 canonical 重定向：`Host: 127.x.x.x` / `[::1]` 的请求 302 跳转到 `localhost:<port><uri>`，把两条入口收敛到同一 origin —— 避免浏览器把 `127.0.0.1` 与 `localhost` 视为不同站点导致 cookie / localStorage 不互通

- **前端鉴权 fetch 联动**（[[14-Web服务]]）
  - `lib/api.ts` 中 `apiGet` / `authedFetch` 一律加 `credentials: 'include'`，确保 cookie 跟随请求；`main.tsx` 改异步 `await consumeUrlToken()` 后再 `createRoot`，避免首屏闪登录页

- **WebServerService 路由**（[[14-Web服务]]）
  - 新增 `POST /api/auth/exchange`（**不**经 AuthFilter）作为 link token → session token 的入口
  - `/api/auth/whoami`、`/api/observers/**`、`/api/icon/**` 现已统一通过 `AuthFilter` 强制鉴权

- **detail 档速率被系统性低估 50%（关键 bug）**（[[14-Web服务]]）
  - 现象：稳定 3840 输入实际显示 1600~1920，刚好一半
  - 根因 1：`ObserverBlockEntity.tick()` 中 `webSampleDue = ... && !mainSampleDue` 让 HP 采样每隔一个桶被主采样挤占，50% 桶为空

  - 修复：移除 `!mainSampleDue` 约束 + `observedTicks / sampleCount` 改为 `Math.max`，`produced/consumed/stock` 仍 sum
  - 通过诊断脚本贴回的真实数据验证修复正确

- **detail 曲线 3200~3700 锯齿波动**（[[06-UI系统]]）

- **EMA 尾部跳动**（[[06-UI系统]]）

  - 修复：反向 pass 仅作用于"稳定段"，尾部 ~3τ 秒的点只经过一次前向 EMA，写入后永不再改

- **Web UI 鼠标进入图表时画面变白崩溃**（[[06-UI系统]]）
  - 交叉点渲染数值未做 NaN 防护 → SVG path 报错连锁卸载
  - 修复：所有 path 坐标过 `Number.isFinite` 守卫

- **净变化曲线在 Web UI 不可见**（[[06-UI系统]]）
  - 用户决策：Web 端舍弃 net 曲线及其交叉点（与 ModernUI 保持差异）

- **detail 档左侧旧数据"嘚儿"一下消失**（[[06-UI系统]]）

- **悬浮提示刷新中断**
  - 数据刷新时 tooltip 和卡片悬浮状态不再被打断闪烁
  - 参照其他页面的修复方式，统一应用到 Storage Network 页面

  - 能量网络页：设备列表、负载分布、过载告警、甜甜圈图
  - 详见 [[06-UI系统]]

- **数据系统**
  - 历史采样环形缓冲区（分钟/小时/天窗口）
  - 玩家 UI 偏好持久化（关注列表、分组、筛选、排序）
  - 详见 [[08-数据持久化]]
