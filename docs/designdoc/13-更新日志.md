## [0.2.1] — 终端物品交互增强与 UI 精细化

### 新增

- **终端物品 Tooltip 信息展示**（[[04-物品系统]]、[[06-UI系统]]）
  - 普通状态显示绑定的观察者坐标与绑定数量
  - 按住 Shift 展开详细信息：各绑定的网络类型、目标坐标、方块类型
  - 信息色调低调（暗灰/暗绿/暗青），不干扰正常游戏

- **终端物品异常贴图系统**（[[04-物品系统]]、[[12-资源结构]]）
  - 新增 `resource_terminal_err.png` 异常状态贴图
  - 物品模型 override 机制：默认显示正常贴图，`bound=1` 时切换至异常模型
  - `ModItemProperties` 注册客户端物品属性，检测 `TAG_BOUND` + `TAG_HAS_NETWORK`
  - 创造模式物品栏/合成台显示正常贴图，取出后自动刷新为异常贴图（`inventoryTick` 机制）

- **观察者网络状态校验**（[[04-物品系统]]）
  - 终端绑定的观察者方块若未连接任何网络，拒绝打开 UI 界面
  - 同时在绑定操作中同步网络状态与绑定详情到物品 NBT

### 修复

- **总览页重置按钮功能补全**（[[06-UI系统]]）
  - 重置筛选按钮同时清除图表的单物品选择，恢复全体物品变化曲线
  - 修复 `refreshInFlight` 竞态：先设置 `selectedItemId(null)` 再发送 `RESET_FILTERS` action

- **右键菜单重复选项**（[[06-UI系统]]）
  - 移除「移动到分组」子菜单中重复的「设为未分组」选项

### 变更

- **顶栏 Chrome 按钮重构**（[[06-UI系统]]）
  - 移除关闭按钮，仅保留尺寸调节按钮（S/M/L）
  - 尺寸按钮改为圆形样式 + 描边轮廓 + 悬停缩放动画 + 波纹反馈
  - 使用 `ShapeDrawable`（radius=1000）+ `StateListDrawable` + `RippleDrawable` 实现

- **Vanilla Screen 冻结**
  - 后续 UI 变更仅涉及 ModernUI Fragment 实现，不再修改 `ResourceTerminalScreen`

## [0.2.0] — 存储网络 UI 重构与速率精度优化

### 新增

- **存储网络页面 ModernUI 全面重构**（[[06-UI系统]]）
  - 完全参照 ResourceTerminalScreen 原始实现，重构 StorageNetworkPageBuilder
  - 双列布局：左侧节点列表 + 右侧物品清单
  - KPI 卡片区域重新实装，修复数据绑定与样式问题
  - 翻译 key 全部修复，画面正确显示中英文文本

- **预估缓冲时间格式升级**
  - 从 MM:SS 改为 DD:HH:MM:SS 格式，支持长周期缓冲显示

- **存储节点网络区分增强**
  - 节点列表显示坐标信息
  - 支持自定义网络名称（弹窗编辑）
  - 关闭 UI 时自动关闭重命名弹窗

- **倒计时式缓冲显示**（[[06-UI系统]]）
  - 两层客户端平滑机制：Rate EMA（α=0.05）+ Countdown-Lock（2%/25% 阈值）
  - 正常运行时缓冲时间平稳逐秒递减，不再大幅跳变

- **服务端速率 EMA 平滑**
  - 新增服务端 EMA（α=0.10），平滑窗口旋转和采样噪声
  - 与客户端 EMA 形成双层平滑链路

- **速率调试日志系统**
  - JVM 参数 `-Dresobs.ratedebug=true` 启用
  - 输出每采样增量和每窗口汇总，用于诊断速率偏差

### 修复

- **速率精度：全链路 double 精度改造**（[[05-网络通信]]、[[03-方块与实体]]）
  - 速率计算从 `long` 改为 `double`，消除整数除法截断噪声
  - 覆盖全链路：ObserverBlockEntity → ObserverDataPayload → ViewModel → PageBuilder
  - `toPerMin` 从 `20L*60L/10` (=120L) 改为 `20.0*60.0/10.0` (=120.0)

- **滚动列表刷新闪烁**（[[06-UI系统]]）
  - 物品速率变更时右侧滚动区域滑块不再闪烁
  - 采用增量更新策略：KPI 卡片标签更新、物品列表结构 key 对比 + 原地更新

- **悬浮提示刷新中断**
  - 数据刷新时 tooltip 和卡片悬浮状态不再被打断闪烁
  - 参照其他页面的修复方式，统一应用到 Storage Network 页面

- **物品列表行高异常**
  - 选择存储节点后右侧列表行高不再异常
  - 物品区段从固定高度改为 WRAP_CONTENT

- **状态筛选按钮三连修复**
  - 修复 lambda 闭包捕获陈旧布尔值（改为动态读取当前状态）
  - 修复 `onDataChanged()` 的 1.5s 抑制窗口导致按钮点击被吞
  - 修复 `tryIncrementalUpdate` 未重建筛选栏（新增 TAG_FILTER_BAR 查找与重建）

### 变更

- **速率管道架构**
  - `ItemDeltaEntry.delta/productionRate/consumptionRate` 类型从 `long` → `double`
  - 网络序列化从 `writeLong`/`readLong` → `writeDouble`/`readDouble`
  - `StorageNetworkViewModel.ItemRow.delta` 和 `burnRatePerMin` → `double`
  - 显示层统一使用 `compact(Math.round(doubleValue))` 保证 compact 函数兼容

## [0.1.1] — 能量网络 UI 增强

### 新增

- **KPI 卡片点击弹窗**（[[06-UI系统]]）
  - 4 张 KPI 卡片（有效输入/有效输出/储能/外储排除）均可点击打开详情弹窗
  - 弹窗支持实时数据刷新（`setDialogContentRefresher`），与主页面同步
  - 弹窗具有入场/退场动画（缩放+淡入淡出），点击遮罩或关闭按钮关闭

- **有效输入弹窗 — 排除设备标注**
  - 被外储排除组关联的输入设备行前添加 `[已排除]` 标签
  - 排除设备使用 muted 色调与有效设备区分

- **储能弹窗 — 无容量 info 提示**
  - 网络没有储能方块时显示 `ℹ 未检测到内部储能容量` 提示
  - 外部容器容量为 0 时显示 `[无容量]` 标签
  - 总计区域无任何有效储能时显示 `ℹ 当前无任何储能容量`

- **用电器负载双指标列**
  - 负载占比（设备消耗 / 总消耗）
  - 供能占用（设备消耗 / 总有效输入）

- **国际化**
  - 新增 20 条 KPI 弹窗相关翻译（zh_cn + en_us）

### 修复

- **设备去重可靠性**（[[06-UI系统]]）
  - 多个输出口连接同一用电器时不再重复计数
  - 快速连接场景下去重 key 从 `displayName` 改为 `extId`（基于位置的唯一 ID）
  - 修复 `refNameMap` 被 `[Cap]`/`[MaxAccept]` 后缀污染的问题（仅从 `.stored` 项存储名称）

- **储能进度条刷新闪烁**
  - 从 `FrameLayout` + `post()` 延迟宽度设置改为 `LinearLayout` + `weightSum` 权重布局
  - 首帧即渲染正确宽度，消除数据刷新时的闪烁

- **电力设备区域实时刷新**
  - 设备列表和电网负载进度条现在随数据更新实时刷新

- **空闲用电器消失**
  - 输出接口不输出电量时设备不再从列表中消失

### 移除

- **电力概要区段**
  - 删除了底部的"电力概要"统计摘要区域（功能已被 KPI 弹窗替代）
  - 移除 `buildPowerStats`、`addStatPair`、`updateStatValues` 方法及 `TAG_STAT_VALUES` 常量

## [0.1.0] — MVP 初始版本

### 新增

- **观察者方块（Observer Block）**
  - 可放置在世界中，绑定到一个资源网络
  - 服务端每 10 tick 采样一次网络数据
  - 支持水平朝向和连接状态纹理切换
  - 详见 [[03-方块与实体]]

- **绑定工具（Binding Tool）**
  - 两步右键绑定流程（选择观察者 → 选择目标）
  - Shift+右键解绑
  - 支持 AE2 网络设备和 Flux Networks 控制器
  - 详见 [[04-物品系统]]

- **资源终端（Resource Terminal）**
  - 绑定到观察者后右键打开仪表盘 GUI
  - 三个标签页：总览、存储网络、能量网络
  - 详见 [[04-物品系统]] 和 [[06-UI系统]]

- **调试终端（Debug Terminal）**
  - 开发用终端，默认启用调试面板

- **AE2 集成**
  - 读取物品/流体存储
  - 计算产量/消耗速率
  - 存储容量指标（字节/类型/单位）
  - 详见 [[07-模组集成]]

- **Flux Networks 集成**（可选）
  - 能量输入/输出速率
  - 存储量/容量
  - 设备列表和外部分组
  - 详见 [[07-模组集成]]

- **Mekanism 辅助集成**（可选）
  - 通过 Flux 集成进行能量单位转换

- **仪表盘 GUI**
  - ModernUI Fragment 主实现 + Vanilla Screen 回退
  - 总览页：KPI 卡片、流量图表、关注列表、物品表格
  - 存储网络页：节点列表、容量 KPI、物品清单、用量摘要
  - 能量网络页：设备列表、负载分布、过载告警、甜甜圈图
  - 详见 [[06-UI系统]]

- **数据系统**
  - 历史采样环形缓冲区（分钟/小时/天窗口）
  - 玩家 UI 偏好持久化（关注列表、分组、筛选、排序）
  - 详见 [[08-数据持久化]]

- **自定义网络通信**
  - ObserverDataPayload (S→C)
  - ObserverRefreshRequestPayload (C→S)
  - ObserverUiActionPayload (C→S)
  - 详见 [[05-网络通信]]

- **国际化**
  - 完整的英文 (en_us) 和中文 (zh_cn) 翻译

- **CI/CD**
  - GitHub Actions 构建流水线
