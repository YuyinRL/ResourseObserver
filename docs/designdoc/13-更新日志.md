## [0.5.0] — Web Dashboard Power Network 重构 & 外储联动

### 新增

- **Web Dashboard Power Network 页面重写**（[[14-Web服务]]、[[06-UI系统]]）
  - 顶部 KPI 行：有效输入 / 有效输出 / 储能 / 外储排除速率（4 卡）
  - 中部双列：左侧负载分布甜甜圈 + 外储控制台，右侧负载进度条 + 电力设备表
  - 底部网络汇总卡片
  - KPI 与外储均支持点击打开 ModernDialog
  - 与游戏内 `PowerNetworkPageBuilder` 布局一一对齐

- **外储自动识别**（`derivePowerAutoDetectedExtIds`）
  - 同时被 PLUG 与 POINT 接口检测到的外部容器自动判定为「双向储能」
  - 与游戏内 `computeAutoDetectedStorageIds` 算法一致
  - 自动识别项在外储对话框显示 `[A]` 徽标，且不可手动取消

- **外储群组联动**（`derivePowerExtCoGroups`）
  - 并查集计算同一设备 `externalRefs` 内的 `extId` 连通分量
  - 用户在 Dialog 中点击单个外储时一并切换其同设备的所有 extIds
  - 行为对齐游戏内 `toggleExternalGroupSelection(relatedIds)`

- **`derivePowerEffectiveStats` 扩展**
  - 接受可选 `effectiveGroups`，将外储容量并入总储能（`stored / capacity`）
  - 计算 `excludedInputPerTick / excludedOutputPerTick / excludedTotalPerTick`

- **负载分布甜甜圈双视图切换**（[[06-UI系统]]）
  - Switch 按钮在「占总负载」与「占总发电」两种视图间切换
  - 占总负载：扇区填满 360°，中心显示当前需求
  - 占总发电：扇区按 `output/input` 缩放并补足 headroom 切片，中心显示余量百分比
  - 解决「发电功率远大于负载时分类挤压」的可读性问题
  - 移植自游戏内 `isPowerDonutUsedOnly` Switch 逻辑

- **Recharts Donut 与 StorageNetwork 同款样式**
  - `innerRadius=56 / outerRadius=80 / paddingAngle=7 / stroke="none"`
  - 启用动画动效与 `<Tooltip>`，下方带圆点的图例列表
  - 中心粗体数值 + 小标签

### 修复

- **Web 端 i18n 缺失键修复**（[[06-UI系统]]）
  - 替换不存在的 key：`power.external.configure → power.external.toggle`、
    `power.summary.totalEnergy/totalMax → power.summary.stored / power.kpi.capacity`
  - 修复 `lines.* / external.dialog.* / external.col.stored / common.none` 等映射
  - i18n key 缺失时不再以原始字符串显示

- **Storage Network Page 加载白屏**（`TypeError: Cannot read properties of undefined`）
  - 修复对 `bindings`/`devices` 为 undefined 时的访问
  - 增加 `Array.isArray` 防御

- **甜甜圈空数据时不显示**
  - 空段落兜底色从 `#1e293b`（不可见）改为 `#334155`
  - 零值切片下限改为 `0.001`，确保 Recharts 始终渲染

### 变更

  - 与游戏内文案一致

- **Sidebar：Storage Network 保留下拉子页（存储 / 合成）**
  - Overview 不再显示下拉箭头

  - `npm run build` → `src/main/resources/assets/resourceobserver/web/assets/index-*.js`

## [0.3.0] — 内置 Web Dashboard & AE2 合成数据

### 新增

- **内置 Web Dashboard HTTP 服务**（[[14-Web服务]]）
  - 服务端启动时自动启动 HTTP 服务（JDK 原生 `HttpServer`，无新增依赖）
  - 默认 `http://127.0.0.1:28080/`，配置项：`enabled` / `host` / `port` / `corsAllowAll`
  - 配置文件 `config/resourceobserver-web.toml`
  - 生命周期绑定 `ServerStartedEvent` / `ServerStoppingEvent`，单人/专用端通用
  - 独立线程池（4 线程），主线程切换使用 `MinecraftServer.submit()` + 3s 超时保护

- **JSON API**（[[14-Web服务]]）
  - `GET /api/health` — 健康与 tick 统计
  - `GET /api/observers` — 所有已加载 Observer 列表
  - `GET /api/observers/{dim}/{x}/{y}/{z}` — 单个 Observer 详情（含 AE2 物品字典 / cell capacity / Flux 能量快照）
  - `GET /api/observers/{dim}/{x}/{y}/{z}/crafting` — AE2 可合成物品 + 活跃 CPU 任务 + 合成存储汇总

- **AE2 合成数据采集器**（[[07-模组集成]]）
  - 新增 `CraftingDataCollector`：纯反射调用 `ICraftingService` 与 `ICraftingCPU`，隔离 API 版本差异
  - 支持 `craftables`（物品上限 1024）、`jobs`、`storageMetrics`（CPU 数、忙碌数、可用字节、协处理器）
  - 反射失败时返回空集合 + 一次性 DEBUG 日志，不抛异常

- **Observer 静态注册表**（[[03-方块与实体]]）
  - `ObserverBlockEntity.LOADED` 在 `onLoad() / setRemoved()` 中自动维护，供 Web API O(1) 枚举

- **占位 Dashboard 首页**（[[12-资源结构]]）
  - `assets/resourceobserver/web/index.html` 自动轮询 `/api/health` 和 `/api/observers`
  - 后续版本将挂载 `Data Visualization Dashboard/` 的 React 构建产物

### 变更

- `ResourceObserverMod` 构造器新增 `WebServerConfig.register(modContainer)` 与 `WebServerService.register()`
- 文档索引 [[00-INDEX]] 追加 [[14-Web服务]] 入口

### 已知限制

- Web Dashboard 的 React 前端尚未接入真实 API（当前为占位页面）
- 无鉴权机制；默认仅监听 `127.0.0.1`，请勿暴露公网
- AE2 `ICraftingCPU.getAvailableStorage()` 在部分老版 API 下可能返回 null，`storage.reliable` 字段会标记为 `false`

## [0.2.3] — 搜索栏 & 拼音搜索 & 甜甜圈切换 & 日志优化

### 新增

- **物品搜索栏**（[[06-UI系统]]）
  - Overview 和 Storage Network 页面新增搜索框，支持按物品显示名称实时过滤
  - 两个页面共享同一搜索词（`ViewModelBridge.searchQuery`），切换 Tab 后保持一致
  - 200ms 防抖机制避免频繁重建，清除按钮 "×" 在有输入时显示

- **拼音搜索支持**（[[07-模组集成]]）
  - 内置 `PinyinMatcher`：基于 GB2312 Level 1 边界表实现拼音首字母匹配（无外部依赖）
  - 支持三种模式：直接字符串包含、纯拼音首字母、混合匹配
  - 可选集成 Just Enough Characters (JEC) 模组：安装后自动委托 PinIn 引擎，支持全拼、混合拼音、模糊音
  - JEC 通过 `MethodHandle` 反射调用，无编译期类路径依赖

- **甜甜圈图显示模式切换**（[[06-UI系统]]）
  - Power Network 页面新增 Switch 组件，可在「含余量」和「仅显示负载分布」之间切换
  - 仅负载模式下扇区填满 360°，中心文字切换为利用率百分比
  - 切换操作直接原地更新甜甜圈数据，响应即时无延迟

### 修复

- **AE2 容量探测日志优化**（[[03-方块与实体]]）
  - WARN 级别精简为一行摘要（坐标 + 网络 + 可用/可靠状态）
  - 完整诊断信息降级为 DEBUG 级别
  - 每个网络 5 分钟限流，避免高频重复日志占用服务器资源

- **Overview 物品跨观察者去重**（[[06-UI系统]]）
  - 多个观察者绑定的网络包含相同物品时，现在正确合并为一行（累加产量/消耗/库存）
  - 使用 `LinkedHashMap<String, TableRow>` 按 itemId 去重 + `saturatingAdd` 防溢出

- **搜索框退格清空失焦**（[[06-UI系统]]）
  - 退格删除至空时搜索框不再失去焦点
  - 新增 `rebuilding` 标志，页面重建期间忽略旧视图的失焦事件
  - `ViewModelBridge.searchBoxFocused` 状态跨重建周期保持

- **搜索提示文本精简**
  - 移除提示文本中多余的括号说明，简化为 `"搜索物品..."` / `"Search items..."`

### 变更

- **Switch 按钮居左对齐**（[[06-UI系统]]）
  - 甜甜圈图切换开关从居中改为居左，与信息区段对齐

  - 节点列表显示坐标信息
  - 支持自定义网络名称（弹窗编辑）

  - 两层客户端平滑机制：Rate EMA（α=0.05）+ Countdown-Lock（2%/25% 阈值）

  - 新增服务端 EMA（α=0.10），平滑窗口旋转和采样噪声
  - 与客户端 EMA 形成双层平滑链路

  - JVM 参数 `-Dresobs.ratedebug=true` 启用

- **速率精度：全链路 double 精度改造**（[[05-网络通信]]、[[03-方块与实体]]）

  - 参照其他页面的修复方式，统一应用到 Storage Network 页面

- **物品列表行高异常**
  - 选择存储节点后右侧列表行高不再异常
  - 物品区段从固定高度改为 WRAP_CONTENT

- **状态筛选按钮三连修复**

  - 修复 `onDataChanged()` 的 1.5s 抑制窗口导致按钮点击被吞
  - 修复 `tryIncrementalUpdate` 未重建筛选栏（新增 TAG_FILTER_BAR 查找与重建）

  - 4 张 KPI 卡片（有效输入/有效输出/储能/外储排除）均可点击打开详情弹窗
  - 弹窗支持实时数据刷新（`setDialogContentRefresher`），与主页面同步
  - 弹窗具有入场/退场动画（缩放+淡入淡出），点击遮罩或关闭按钮关闭

- **有效输入弹窗 — 排除设备标注**

  - 排除设备使用 muted 色调与有效设备区分

- **储能弹窗 — 无容量 info 提示**
  - 网络没有储能方块时显示 `ℹ 未检测到内部储能容量` 提示
  - 外部容器容量为 0 时显示 `[无容量]` 标签
  - 总计区域无任何有效储能时显示 `ℹ 当前无任何储能容量`

- **用电器负载双指标列**
  - 负载占比（设备消耗 / 总消耗）
  - 供能占用（设备消耗 / 总有效输入）

  - 快速连接场景下去重 key 从 `displayName` 改为 `extId`（基于位置的唯一 ID）
  - 修复 `refNameMap` 被 `[Cap]`/`[MaxAccept]` 后缀污染的问题（仅从 `.stored` 项存储名称）

- **电力设备区域实时刷新**
