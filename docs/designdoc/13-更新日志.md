## [0.6.0] — Web Detail 图表精度重构 & 自适应高精度采样

### 新增

- **Web Dashboard 高精度短期采样层**（[[14-Web服务]]、[[08-数据持久化]]）
  - 新增 `WebHighPrecisionSampler`：Web detail 图表专用的内存环形缓冲（1200 桶 × 0.25s = 5 分钟），不写入存档
  - 自适应触发：仅在前端 detail 页/单物品图表打开时按需激活，10 秒 demand TTL，关闭后自动停采
  - 采样间隔分级：全局视图 5 tick（0.25s）、单物品视图 2 tick（0.1s）
  - `ObserverBlockEntity.tick()` 同时驱动主采样器和 HP 采样器，二者节奏独立互不影响
  - 通过 `/api/observers/{id}/history?range=detail` 暴露最近 1 分钟亚秒级曲线
  - 通过 `/debug/sampler` 暴露 demand TTL、recentBuckets、sampleCount 等诊断字段

- **3 秒滑动窗口速率聚合**（[[14-Web服务]]）
  - `HistoryHandler.buildHighPrecisionBody`：每个输出点对最近 12 桶（3 秒）求 produced/consumed 总和
  - 用 `观察 tick 总数 / 1200 = produced·分钟⁻¹` 公式还原速率，消除单桶 0.25s 内的零星突发噪声

- **诊断脚本 `scripts/diagnose-detail-chart.mjs`**
  - 循环调用 `/api/observers`、`/history?range=detail`、`/debug/sampler` 端点
  - 输出 history.tail、debug.recentBuckets、rolling-window 重算结果
  - 用法：`node scripts\diagnose-detail-chart.mjs --samples=N --interval=2000`

- **Web 端 detail 档时间颗粒度切换**（[[06-UI系统]]）
  - Overview 流量图表 Tab：detail（1 分钟/0.25 秒）/ short / medium / long 四档
  - 与游戏内 ModernUI 的 ChartScope/ChartWindow 一一对应

- **关注列表交互动效**（[[06-UI系统]]）
  - 添加/删除/折叠：`framer-motion` 进出场动画、五角星点击 pulse 反馈
  - 列表为空时折叠为占位卡片，避免 Observer 快照卡片孤立

- **资源列表双视图模式**（[[06-UI系统]]）
  - 列表视图：完整字段排序
  - 九宫格视图：方格悬浮显示详细 tooltip
  - `localStorage` 持久化用户偏好

- **物品图标 `/icon/{namespace}/{path}` 端点**（[[14-Web服务]]）
  - `IconHandler` + 客户端贴图缓存
  - `ItemNameResolver` 注入 `translationKey` + 当前服务端语言下的 `displayName`
  - Web 端按 i18n 切换中/英文物品名

- **图表交互优化**（[[06-UI系统]]）
  - Tooltip 跟随鼠标（曾经固定贴交叉点遮挡）
  - 交叉点位置在鼠标静止时实时刷新
  - 单击物品卡片实时切换流量曲线为该物品
  - 左上角显示「总体曲线 / 物品名称」标识
  - 右侧新数据进入采用淡入遮罩，左侧旧数据采用淡出（避免一秒一节抖动入场）
  - 时间轴拖拽行为：仅在最右/最左时随时间滚动，中段保持静止以便定位极值

### 修复

- **detail 档速率被系统性低估 50%（关键 bug）**（[[14-Web服务]]）
  - 现象：稳定 3840 输入实际显示 1600~1920，刚好一半
  - 根因 1：`ObserverBlockEntity.tick()` 中 `webSampleDue = ... && !mainSampleDue` 让 HP 采样每隔一个桶被主采样挤占，50% 桶为空
  - 根因 2：`WebHighPrecisionSampler.NetworkBuffer.accumulate / ItemBuffer.accumulate` 多网络聚合时把 `observedTicks` 用 `saturatingAdd` 累加，但同 wall-clock tick 的时间不能叠加 → 分母翻 N 倍
  - 修复：移除 `!mainSampleDue` 约束 + `observedTicks / sampleCount` 改为 `Math.max`，`produced/consumed/stock` 仍 sum
  - 通过诊断脚本贴回的真实数据验证修复正确

- **detail 曲线 3200~3700 锯齿波动**（[[06-UI系统]]）
  - AE2 ~1Hz commit 节奏导致 12 桶滑动窗口内 fat 桶数在 5/6/7 跳变
  - 前端 `Overview.tsx::smoothFlowSeries` 启用 τ≈1.2s 零相位 EMA 压平

- **EMA 尾部跳动**（[[06-UI系统]]）
  - 反向 EMA 让最近点依赖未来上下文，新点到来时旧最近点的平滑值被改写 → 视觉抖动
  - 修复：反向 pass 仅作用于"稳定段"，尾部 ~3τ 秒的点只经过一次前向 EMA，写入后永不再改

- **Web UI 鼠标进入图表时画面变白崩溃**（[[06-UI系统]]）
  - 交叉点渲染数值未做 NaN 防护 → SVG path 报错连锁卸载
  - 修复：所有 path 坐标过 `Number.isFinite` 守卫

- **净变化曲线在 Web UI 不可见**（[[06-UI系统]]）
  - 用户决策：Web 端舍弃 net 曲线及其交叉点（与 ModernUI 保持差异）

- **detail 档左侧旧数据"嘚儿"一下消失**（[[06-UI系统]]）
  - 增加左侧渐出 mask 与可视区域裁剪，淡出位置从外轴左边界移到稍靠内的位置

### 变更

- **流量曲线名称**：「资源流包络图」→「物品产消趋势 / 库存趋势」（[[06-UI系统]]）
- **客户端 EMA 策略**（[[08-数据持久化]]）
  - detail 档（≤0.5s）：τ=1.2s（之前关闭）
  - short/medium 档：τ=1.5s
  - long 档（≥5s）：不再叠加 EMA
- **请求 detail 数据时自动注册 demand**（[[14-Web服务]]）
  - `GET /history?range=detail&item={id}` 同时为对应 observer/itemId 续命 demand TTL
- **`MetaHandler` 增加 `bucketSeconds` 字段**，前端用以校准 X 轴
- **`ChartWindow` / `ObserverDataPayload` 增加 detail 档枚举**（[[05-网络通信]]）

### 已知限制

- AE2 自身 commit 节奏 ~1Hz：单桶 0.25s 内可能 7000 件突发 + 3 桶为 0；3s 滑动窗 + 前端 EMA 已大幅压平，但极端突发仍会有 ±10% 残余抖动
- HP 采样器 demand TTL 10s：长时间停留在非 detail 页面，HP buffer 会逐步清空，回到 detail 页有 ~4 秒冷启动期（MIN_VALID_BUCKETS=16）
