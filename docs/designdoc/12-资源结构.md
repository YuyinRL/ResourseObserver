# 资源结构

## 目录总览

```
src/main/
├── resources/
│   ├── assets/resourceobserver/        ← 客户端资源
│   │   ├── atlases/                    ← 精灵图集定义
│   │   ├── blockstates/               ← 方块状态模型映射
│   │   ├── lang/                      ← 国际化语言文件
│   │   ├── models/                    ← 方块和物品模型
│   │   ├── shaders/                   ← 自定义 GLSL 着色器
│   │   └── textures/                  ← 纹理文件
│   └── data/resourceobserver/         ← 服务端数据包
│       ├── loot_tables/blocks/        ← 方块掉落表
│       └── recipe/                    ← 合成配方
├── templates/
│   └── META-INF/                      ← 模组元数据模板
│       └── neoforge.mods.toml
└── generated/resources/               ← 数据生成器输出（通过 sourceSets 配置包含）
```

## 客户端资源 (assets)

### 方块状态 (blockstates/)

| 文件 | 说明 |
|------|------|
| `observer_block.json` | 观察者方块状态 → 模型映射（含朝向和连接状态变体） |

### 模型 (models/)

#### 方块模型 (models/block/)

| 文件 | 说明 |
|------|------|
| `observer_block.json` | 观察者方块 3D 模型 |

#### 物品模型 (models/item/)

| 文件 | 说明 |
|------|------|
| `binding_tool.json` | 绑定工具物品模型 |
| `resource_terminal.json` | 资源终端物品模型 |
| `debug_terminal.json` | 调试终端物品模型 |

### 纹理 (textures/)

#### 方块纹理 (textures/block/)

| 文件 | 说明 |
|------|------|
| `observer_block.png` | 观察者方块（未连接状态） |
| `observer_block_on.png` | 观察者方块（已连接状态） |
| 其他变体 | 不同面的纹理 |

> 方块连接状态通过 `CONNECTED` BlockState 属性切换纹理。

#### 物品纹理 (textures/item/)

| 文件 | 说明 |
|------|------|
| `binding_tool.png` | 绑定工具图标 |
| `resource_terminal.png` | 资源终端图标 |
| `debug_terminal.png` | 调试终端图标 |

#### GUI 纹理 (textures/gui/)

| 路径 | 说明 |
|------|------|
| `textures/gui/sprites/terminal/` | 终端 GUI 精灵（标签页图标、KPI 图标等） |
| 其他 GUI 纹理 | 屏幕背景和装饰元素 |

精灵 ID 在 `TerminalSprites` 类中定义，渲染时通过精灵 ID 引用。

### 精灵图集 (atlases/)

定义精灵图集（Sprite Atlas），将多个小纹理打包到一个大纹理图集中。

### 着色器 (shaders/)

| 路径 | 说明 |
|------|------|
| `shaders/core/` | 自定义 GLSL 着色器，用于图表渲染 |

由 `ChartRenderShaders` 类管理加载和使用。详见 [[06-UI系统]]。

### 语言文件 (lang/)

| 文件 | 语言 | 覆盖范围 |
|------|------|---------|
| `en_us.json` | 英文 | 完整 |
| `zh_cn.json` | 简体中文 | 完整 |

#### 翻译键分类（100+ 条目）

| 类别 | 键前缀 | 示例 |
|------|--------|------|
| 方块/物品名称 | `block.resourceobserver.` / `item.resourceobserver.` | `block.resourceobserver.observer_block` |
| 绑定消息 | `message.resourceobserver.` | `message.resourceobserver.bind_success` |
| 屏幕标签 | `screen.resourceobserver.` | `screen.resourceobserver.terminal_title` |
| KPI 标签 | `screen.resourceobserver.overview.section.kpi_*` | `kpi_production`, `kpi_consumption` |
| 趋势文本 | `screen.resourceobserver.overview.kpi.trend.*` | `trend.vs_previous`, `trend.unavailable` |

> 添加新的 UI 文本时，必须同时更新 `en_us.json` 和 `zh_cn.json`。

## 模组元数据模板

`src/main/templates/META-INF/neoforge.mods.toml`

使用 Gradle 属性展开（`${variable}` 语法），由 `generateModMetadata` 任务处理。

### 关键声明

```toml
modLoader = "javafml"
loaderVersion = "${loader_version_range}"
license = "${mod_license}"

[[mods]]
modId = "${mod_id}"
version = "${mod_version}"
displayName = "${mod_name}"

# 依赖声明
[[dependencies.resourceobserver]]
modId = "neoforge"       # 必需
[[dependencies.resourceobserver]]
modId = "minecraft"      # 必需
[[dependencies.resourceobserver]]
modId = "ae2"            # 必需，versionRange="[19.2.0,)"
[[dependencies.resourceobserver]]
modId = "modernui"       # 必需（客户端），side="CLIENT"
```

详见 → [[10-构建与开发]] 中模板展开机制

## 数据生成

`sourceSets` 配置包含数据生成器输出：

```gradle
sourceSets.main.resources {
    srcDir('src/generated/resources')
    exclude("**/*.bbmodel")           // BlockBench 项目文件
    exclude("src/generated/**/.cache") // 生成缓存
}
```

通过 `./gradlew runData` 执行数据生成，输出到 `src/generated/resources/`。

---

## 排除规则

以下文件类型从构建输出中排除：

| 模式 | 说明 |
|------|------|
| `**/*.bbmodel` | BlockBench 3D 建模项目文件（仅编辑时使用） |
| `src/generated/**/.cache` | 数据生成缓存（避免重复生成） |

## 添加新资源的清单

添加新方块/物品时需要创建的资源文件：

- [ ] `assets/resourceobserver/blockstates/<block_name>.json`
- [ ] `assets/resourceobserver/models/block/<block_name>.json`
- [ ] `assets/resourceobserver/models/item/<item_name>.json`
- [ ] `assets/resourceobserver/textures/block/<block_name>.png`
- [ ] `assets/resourceobserver/textures/item/<item_name>.png`
- [ ] `assets/resourceobserver/lang/en_us.json` — 添加翻译键
- [ ] `assets/resourceobserver/lang/zh_cn.json` — 添加翻译键
- [ ] `data/resourceobserver/loot_tables/blocks/<block_name>.json`
- [ ] `data/resourceobserver/recipe/<recipe_name>.json`
