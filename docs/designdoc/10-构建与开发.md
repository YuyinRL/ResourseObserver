# 构建与开发

## 环境要求

| 要求 | 版本 |
|------|------|
| Java | 21 (Mojang 在 1.21.1 分发 Java 21) |
| Gradle | 通过 wrapper 管理（BIN 发行版） |
| IDE | IntelliJ IDEA（推荐）或 Eclipse |

## Gradle 命令

### 构建

```shell
# 构建 mod JAR
./gradlew build

# 完全清理并重建
./gradlew clean build

# 刷新依赖缓存
./gradlew --refresh-dependencies
```

### 运行

```shell
# 启动 Minecraft 客户端（开发环境，含 mod）
./gradlew runClient

# 启动无 GUI 服务端
./gradlew runServer

# 启动数据生成器
./gradlew runData

# 启动 GameTest 服务器（执行所有注册的游戏测试）
./gradlew runGameTestServer
```

### 发布

```shell
# 发布到本地 Maven 仓库（项目根目录下 repo/）
./gradlew publish
```

### Maven 仓库

| 仓库 | URL | 内容 |

| ModMaven | `modmaven.dev` | Mekanism |
| IzzelAliz Maven | `maven.izzel.io/releases` | ModernUI |

### 依赖分类

```gradle
// === 编译 + 运行 ===
implementation "icyllis.modernui:ModernUI-NeoForge:${modernui_mc_version}"

// === 仅编译（API 头文件） ===
compileOnly "org.appliedenergistics:appliedenergistics2:19.2.17:api"
compileOnly "mekanism:Mekanism:${mekanism_version}:api"
compileOnly "curse.maven:flux-networks-248020:6089446"

// === 仅本地运行时（开发测试） ===
localRuntime "org.appliedenergistics:appliedenergistics2:19.2.17"
localRuntime "mekanism:Mekanism:${mekanism_version}"
localRuntime "curse.maven:flux-networks-248020:6089446"
```

> `localRuntime` 是自定义配置，继承自 `runtimeClasspath`，不传递给下游 mod。

### ModernUI 排除规则

ModernUI 依赖需要排除运行时已由 Minecraft/NeoForge 提供的库：

```gradle
def modernUiExcludes = { dep ->

    dep.exclude group: "org.apache.logging.log4j"
    dep.exclude group: "com.google.code.findbugs", module: "jsr305"
    dep.exclude group: "org.jetbrains", module: "annotations"
    dep.exclude group: "com.ibm.icu", module: "icu4j"
    dep.exclude group: "it.unimi.dsi", module: "fastutil"
}
```

## 运行配置

NeoForge ModDevGradle 自动生成以下运行配置：

| 配置 | 说明 | 特殊参数 |
|------|------|---------|
| `client` | 客户端（含 GUI） | enabledGameTestNamespaces |
| `server` | 服务端（--nogui） | enabledGameTestNamespaces |
| `gameTestServer` | 游戏测试服务器 | 执行所有测试后退出 |
| `data` | 数据生成器 | --mod, --all, --output, --existing |

所有配置共享：
- 日志标记：`REGISTRIES`
- 日志级别：`DEBUG`

## 元数据模板

`src/main/templates/META-INF/neoforge.mods.toml` 使用 Gradle 属性展开：

```toml
modLoader="javafml"
loaderVersion="${loader_version_range}"
license="${mod_license}"

[[mods]]
modId="${mod_id}"
version="${mod_version}"
displayName="${mod_name}"
```

`generateModMetadata` 任务自动处理模板展开，IDE 同步时也会自动执行。

> ⚠️ 编辑 `src/main/templates/` 下的模板文件，不要修改 `build/generated/` 下的生成输出。

## CI/CD

### GitHub Actions

`.github/workflows/build.yml`：

```yaml
on: [push, pull_request]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - Checkout (fetch-depth: 0, fetch-tags: true)
      - Setup JDK 21 (temurin)
      - Setup Gradle
      - chmod +x gradlew
      - ./gradlew build
```
