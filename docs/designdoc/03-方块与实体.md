# 方块与实体

## ObserverBlock

**类路径：** `world.block.ObserverBlock`  
**继承：** `BaseEntityBlock`  
**关联注册：** [[09-注册系统]] → `ModBlocks.OBSERVER_BLOCK`

### 方块状态

| 属性 | 类型 | 说明 |
|------|------|------|
| `FACING` | `DirectionProperty` | 水平朝向（放置时面向玩家对面） |
| `CONNECTED` | `BooleanProperty` | 是否已绑定网络（影响纹理切换） |

### 交互行为

| 操作 | 条件 | 行为 |
|------|------|------|
| 右键（持有 BindingTool） | — | 跳过默认交互，交由物品处理 |
| 右键（持有 ResourceTerminal） | — | 跳过默认交互，交由物品处理 |
| 右键（空手） | — | 聊天栏显示绑定状态信息 |
| Shift+右键（空手） | Debug 模式 | 显示调试信息 |

### Ticker 机制

- 仅在**服务端**注册 `BlockEntityTicker`
- 调用 `ObserverBlockEntity::tick` 进行周期性采样
- 客户端不执行 tick 逻辑

### 编解码

使用 `simpleCodec(ObserverBlock::new)` 提供 `MapCodec<ObserverBlock>`，用于方块序列化。

## ObserverBlockEntity

**类路径：** `world.block.entity.ObserverBlockEntity`  
**继承：** `BlockEntity`  
**关联注册：** [[09-注册系统]] → `ModBlockEntities.OBSERVER_BLOCK_ENTITY`

这是整个模组的**核心采样引擎**，负责服务端数据采集。

### 核心数据结构

```java
// 网络绑定记录
public record BoundEntry(
    String networkType,    // "AE2_ITEMS" | "FLUX_ENERGY"
    String networkId,      // "targetBlockId@posLong"
    String targetBlockId   // 目标方块注册名
)

// 存储容量指标
public record Ae2CellCapacityMetrics(
    long itemBytesUsed, long itemBytesTotal,
    long itemTypesUsed, long itemTypesTotal,
    long fluidBytesUsed, long fluidBytesTotal,
    long fluidTypesUsed, long fluidTypesTotal,
    long externalItemTypes, long externalFluidTypes,
    long externalItemUnits, long externalFluidUnits
)
```

### 采样参数

| 常量 | 值 | 说明 |
|------|-----|------|
| `SAMPLE_INTERVAL` | 10 tick | 采样间隔（0.5 秒） |
| `RATE_WINDOW_SAMPLES` | 24 | 双缓冲窗口采样数（各 12 秒） |
| `WARMUP_SAMPLES` | 4 | 启动阶段跳过的采样数（AE2 缓存稳定期） |

### 状态字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `bindings` | `List<BoundEntry>` | 当前所有网络绑定 |
| `statsMap` | `Map<String, BindingStats>` | 每个网络的统计数据 |
| `dataStore` | `Ae2DataStore` | AE2 采样数据容器（v0.8.0 抽出，v0.8.1 收紧封装：包外仅通过领域方法访问） |
| `sampler` | `Ae2Sampler` | AE2 有状态采样器（v0.8.1：持 dataStore + gridResolver + debugInfoMap，无反向回调） |
| `gridResolver` | `Ae2GridResolver` | AE2 Grid 解析与容量告警限流（v0.8.1 抽出） |
| `fluxStore` | `FluxDataStore` | Flux 采样结果容器（v0.8.1 抽出） |
| `fluxSampler` | `FluxSampler` | Flux 网络采样器（v0.8.1 抽出） |
| `debugInfoMap` | `Map<String, String>` | 调试信息（每网络一条），共享给采样器与调试消息构建器 |

> v0.8.1 模块化收尾：主类压缩到 ~460 行，仅保留字段/调度/绑定/NBT 职责。
> 采样链按"AE2 ↔ Flux"双路对称：`{Ae2Sampler, Ae2DataStore, Ae2GridResolver, Ae2CellProber}`
> 与 `{FluxSampler, FluxDataStore}` 各成一组；`networkId` 字符串协议封装在 `NetworkRef`；
> 调试消息构建移至 `debug/ObserverDebugMessageBuilder`。

### 采样流程

```
tick() 被调用
  ├── tickCounter++ 
  ├── 如果 tickCounter < SAMPLE_INTERVAL → 返回
  ├── 重置 tickCounter
  ├── 遍历 bindings:
  │   ├── AE2_ITEMS:
  │   │   ├── 通过 IStorageService 获取物品/流体清单
  │   │   ├── 与上次快照对比计算 delta
  │   │   ├── EMA 平滑更新 ratesPerMin
  │   │   ├── 更新容量指标 (Ae2CellCapacityMetrics)
  │   │   └── 调用 HistoryRecorder.recordSample()
  │   └── FLUX_ENERGY:
  │       ├── 调用 FluxNetworksIntegration.probeFluxNetwork()
  │       ├── 读取输入/输出速率、存储量、容量
  │       └── 调用 HistoryRecorder.recordSample()
  └── 标记 setChanged()（触发存档保存）
```

### 公共方法

| 方法 | 说明 |
|------|------|
| `addBinding(type, id, blockId)` | 添加网络绑定 |
| `clearAllBindings()` | 清除所有绑定 |
| `createStatusMessage()` | 生成聊天栏状态信息 |
| `createDebugStatusMessages()` | 生成调试信息列表 |

### NBT 持久化

方块实体数据随区块保存到世界存档。`saveAdditional()` 和 `loadAdditional()` 序列化所有绑定信息和统计数据。

> ⚠️ 历史采样数据不存储在方块实体中，而是通过 [[08-数据持久化]] 的 `ObserverHistorySavedData` 以世界级 SavedData 形式存储。

### 与其他模块的关系

- **注册：** [[09-注册系统]] 中通过 `DeferredRegister` 注册
- **物品交互：** [[04-物品系统]] 中的 `BindingToolItem` 调用 `addBinding()` / `clearAllBindings()`
- **历史记录：** 采样结果写入 [[08-数据持久化]] 的 `HistoryRecorder`
- **模组集成：** Flux 采样委托给 [[07-模组集成]] 的 `FluxNetworksIntegration`
- **网络通信：** 数据通过 [[05-网络通信]] 的 `ObserverDataPayload` 发送到客户端
