# 代码规范

## 概述

本项目遵循 **Google Java Style** 基线，结合项目自身约定。以下规范来源于项目内部的《AI Agent Prompt for Gradle Java Project Code Standardization》文档。

> **核心原则：** 项目内部已有的约定优先于通用规范。一致性高于正确性——不要在局部引入与项目整体风格不同的写法。

---

## 注释语言

> ⚠️ **关键约定：所有注释必须使用中文（Chinese）编写。**

包括：
- Javadoc 注释（`/** ... */`）
- 行内注释（`// ...`）
- 块注释（`/* ... */`）
- `build.gradle` 中的注释

```java
// ✅ 正确
/** 将采样数据写入历史记录环形缓冲区。 */
public void recordSample(...) { ... }

// ❌ 错误
/** Writes sample data to the history ring buffer. */
public void recordSample(...) { ... }
```

## 命名规范

| 类型 | 规则 | 示例 |
|------|------|------|
| 类/接口/枚举 | PascalCase，自描述 | `ObserverBlockEntity`, `FluxNetworksIntegration` |
| 方法/变量 | camelCase | `addBinding()`, `chartWindow` |
| 常量 | UPPER_SNAKE_CASE | `SAMPLE_INTERVAL`, `TAG_DIMENSION` |
| 包名 | 全小写，点分隔 | `com.yuyinrl.resourceobserver.world.block` |
| 测试方法 | 体现场景和期望结果 | `testCreateBinding_WithInvalidTarget_ThrowsException` |

> 禁止使用拼音或非标准缩写作为标识符，所有名称使用清晰的英文。

## 代码格式

### 缩进与行宽

- 统一使用**空格**缩进（禁止 Tab 和空格混用）
- 单行最大 **120 字符**，超长代码合理换行
- 编码：**UTF-8**（在 `build.gradle` 中已配置 `options.encoding = 'UTF-8'`）

### Import 规范

- **禁止通配符导入**（`import xxx.*`）
- 删除所有未使用的 import
- 导入顺序：`java.*` → `javax.*` → 第三方包 → 项目内部包
- 组间空行分隔

```java
import java.util.List;
import java.util.Map;

import net.minecraft.core.BlockPos;
import net.minecraft.world.level.Level;

import icyllis.modernui.fragment.Fragment;

import com.yuyinrl.resourceobserver.network.ObserverDataPayload;
```

## 代码结构

### 单一职责

- 单个类不超过 **2000 行**
- 单个方法不超过 **80 行**
- 过长逻辑拆分为辅助方法

### Guard Clause 优先

嵌套层级不超过 **3 层**，使用 Guard Clause 提前返回：

```java
// ✅ 推荐
public void process(Player player) {
    if (player == null) return;
    if (!player.isAlive()) return;
    // 核心逻辑...
}

// ❌ 避免
public void process(Player player) {
    if (player != null) {
        if (player.isAlive()) {
            // 核心逻辑...
        }
    }
}
```

### 资源管理

优先使用 `try-with-resources` 自动关闭资源。

### 清理

- 删除所有未使用的变量、字段、私方法
- 消除重复代码，提取公共工具方法

## 日志规范

- **禁止** `System.out.println()` / `System.err.println()`
- 统一使用 SLF4J（通过 `LoggerFactory.getLogger()`）
- 正确使用日志级别：
  - `DEBUG`：开发调试信息
  - `INFO`：正常运行里程碑
  - `WARN`：可恢复的异常情况
  - `ERROR`：需要关注的错误

---

## 异常处理

- **禁止空 catch 块**：必须处理或向上抛出
- 优先使用 `Optional` 处理可空值

## 项目特有约定

### DeferredRegister 注册

详见 [[09-注册系统]]，每个类别一个注册类，静态 `register(IEventBus)` 入口。

### Payload 定义

使用 `record` 类型 + 静态 `TYPE` + `STREAM_CODEC`，详见 [[05-网络通信]]。

### ViewModel 不可变

所有 ViewModel 使用 `record` 类型，一旦构建不可修改。状态变更通过重新构建 ViewModel。

### 适配器模式

模组集成通过 `integration/` 包的适配器类，必须包含 `isAvailable()` 可用性检查，详见 [[07-模组集成]]。

## Javadoc 约定

公共类和公共方法必须有完整的 Javadoc：

```java
/**
 * 将观察者绑定到指定的资源网络。
 *
 * @param networkType 网络类型标识（如 "AE2_ITEMS"）
 * @param networkId   网络唯一标识
 * @param blockId     目标方块注册名
 * @throws IllegalArgumentException 如果网络类型不受支持
 */
public void addBinding(String networkType, String networkId, String blockId) {
    // ...
}
```

复杂业务逻辑必须添加行内注释说明**意图**，而非重复描述代码行为。
