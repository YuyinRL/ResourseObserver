## 功能定位

Resource Observer 是一个 Minecraft NeoForge 模组，用于**监控游戏内资源网络**。玩家可以通过观察者方块绑定到 AE2 存储网络或 Flux Networks 能量网络，实时采集网络指标并在终端 GUI 中以仪表盘形式展示。

## 核心玩法对象

### 1. 观察者方块（Observer Block）

放置在世界中的功能方块，核心职责：

- 绑定到**一个**资源网络（AE2 或 Flux）
- 每 10 tick（0.5 秒）服务端采样一次网络数据
- 维护滚动统计数据（产量、消耗量、净变化）
- 存储历史采样数据到世界存档

详见 → [[03-方块与实体]]

### 2. 绑定工具（Binding Tool）

手持物品，用于将观察者方块绑定到目标网络：

- **两步绑定流程**：右键选择观察者 → 右键选择目标网络方块
- Shift+右键观察者 → 解除所有绑定
- 支持 AE2 任意网络设备和 Flux Networks 控制器

详见 → [[04-物品系统]]

### 3. 资源终端（Resource Terminal）

手持物品，用于查看观察者收集的数据：

- 右键观察者方块 → 绑定终端到该观察者
- 空手右键（已绑定状态） → 打开仪表盘 GUI
- 三个标签页：总览、存储网络、能量网络

详见 → [[04-物品系统]] 和 [[06-UI系统]]

## 依赖关系

| 依赖 | 类型 | 说明 |

| NeoForge | 必需 | 基础平台 |
| Minecraft 1.21.1 | 必需 | 游戏版本 |

## MVP 范围

### 包含

- 游戏内观察者注册与网络绑定
- 服务端周期性采样（AE2 物品、Flux 能量）
- 历史数据追踪（分钟/小时/天窗口）
- ModernUI 增强仪表盘 + 原版 Screen 回退
- 总览、存储网络、能量网络三个标签页
- 关注列表、分组、排序、筛选功能
- 玩家 UI 偏好持久化

### 不包含（明确推迟）

- Web 仪表盘 / HTTP 服务
- 远程访问与认证
- 区分机器产出 vs 玩家手动放入
- 自动绑定邻近方块
- 高级图表渲染（超出基本趋势显示）
