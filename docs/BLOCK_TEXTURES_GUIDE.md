# 观察者方块纹理准备指南

所有纹理文件均为 PNG 格式，需放入以下目录：

```
src/main/resources/assets/resourceobserver/textures/block/
```

## 需要准备的文件

| 文件名 | 尺寸 | 说明 |
|---|---|---|
| `observer_front.png` | 16 × (16 × 帧数) | **正面（屏幕面）**，动画纹理，所有帧从上到下竖向排列 |
| `observer_back.png` | 16 × 16 | 背面，静态纹理 |
| `observer_side.png` | 16 × 16 | 左右两侧面，静态纹理（左右共用同一张） |
| `observer_top.png` | 16 × 16 | 顶面，静态纹理 |
| `observer_bottom.png` | 16 × 16 | 底面，静态纹理 |

## 正面动画纹理说明

`observer_front.png` 是唯一的动画纹理。制作方式：

1. 宽度固定 **16 像素**
2. 高度 = **16 × 帧数**（例如 4 帧动画 → 16×64，8 帧 → 16×128）
3. 每帧从上到下依次排列，帧编号从 0 开始

示意图（以 4 帧为例，实际为 16×64 像素）：

```
┌────────────────┐ ← 第 0 帧 (y: 0~15)
│                │
│   屏幕状态 1   │
│                │
├────────────────┤ ← 第 1 帧 (y: 16~31)
│                │
│   屏幕状态 2   │
│                │
├────────────────┤ ← 第 2 帧 (y: 32~47)
│                │
│   屏幕状态 3   │
│                │
├────────────────┤ ← 第 3 帧 (y: 48~63)
│                │
│   屏幕状态 4   │
│                │
└────────────────┘
```

## 动画配置

动画参数已写在 `observer_front.png.mcmeta` 中：

- **frametime = 10**：每帧显示 10 个游戏 tick（0.5 秒）
- **interpolate = true**：帧与帧之间平滑过渡

如需调整：
- 想播放更快 → 减小 `frametime`（例如 5 = 0.25 秒/帧）
- 想硬切换而非渐变 → 把 `interpolate` 改为 `false`
- 想自定义播放顺序 → 添加 `"frames": [0, 2, 1, 3]`

## 方块朝向

方块放置时**正面自动面向玩家**（水平四方向旋转）。模型中各纹理对应的面：

```
        ┌──────────┐
        │   top    │
        │ (顶面)   │
   ┌────┼──────────┼────┐
   │side│  front   │side│
   │(左)│ (正面)   │(右)│
   └────┼──────────┼────┘
        │  bottom  │
        │ (底面)   │
        └──────────┘
              ↑ 背面: back
```

## 绘制建议

- 正面可以画一个"屏幕"外框（深色边框 + 发光内容区），动画帧只变化内容区
- 侧面/背面/顶面/底面可以用金属/机械风格的静态纹理
- 保持 Minecraft 原版的像素风格，每个纹理建议不超过 5~10 种颜色
- 静态纹理确保不透明（不含 alpha 通道），正面纹理同理
